Diagnostic order

Capture the response request_id and X-Request-ID header. For a

gateway-proxied call, also keep X-Polygres-Upstream-Request-ID .

Check the affected project, job, migration, or configuration state.

Look up the error code and apply the listed corrective action.

Use the symptom-first troubleshooting page if no typed error was returned.

Escalate to support if the issue persists.
